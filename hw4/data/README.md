# hw4/data — course data goes here (not in the repo)

The database and product photos are course-provided files and are **not committed** (see `.gitignore`).

Unzip the course's `data.zip` here so the folder looks like:

```
hw4/data/
├── campus_customs.db        # SQLite: catalogue, inventory, users, chat_messages
└── products/                # 102 product photos (*.jpg)
```

On first start the backend adds a `sessions` table and two extra `chat_messages` columns automatically.
